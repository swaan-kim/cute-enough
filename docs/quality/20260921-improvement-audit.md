## 진행 기록

### 1. 서버 — 구현·검증 완료

- 인증 upstream의 HTTP 200 본문이 끊기면 잘못된 사용자 401 대신 일시 오류 503. 실패 결과는 인증 캐시에 넣지 않는다. 회귀 18개.
- 요청 제한 거절·제한기 장애 뒤 티켓 상태를 다시 읽던 추가 RPC를 제거했다. 실제 Edge 처리기의 8단계 테스트로 업무 조회 0회를 검사하고 일반 오류 복구는 유지했다.
- 업로드 본문을 읽다 연결이 취소되면 pending reader를 취소하고 408로 끝낸다. 이미 취소된 요청, source cleanup 실패/무기한 대기, reader lock·리스너 해제를 포함해 21개 검사.

### 2. 데이터 — 후속 마이그레이션·격리 검증 완료

`20260921000100_photo_unlock_integrity.sql`은 사진 ID와 강아지 ID를 복합 FK로 묶고 사진 삭제의 연쇄 수집권 삭제를 막는다. 정상적인 비활성화·복구·정렬·추가 사진 승인은 유지한다. 기존 잘못된 연결은 삭제하거나 고치지 않고 전체 마이그레이션을 실패시킨다.

새 제약 회귀 7개와 최신 마이그레이션 체인의 다중 사용자 여정 9개를 통과했다. A 등록→초안→명시적 SVG 승인→B 수집/좋아요→A 집계→추가 사진 승인에서 원본·해시·요청·수집·좋아요를 검사한다. 과거 도감 초기화 SQL은 이력으로 보존하고, 이번 검증에서는 설치만 했으며 초기화 실행 기록 0을 확인했다. **운영 DB에는 적용하지 않았다.**

- 내 목록은 최초 로딩만 전체 대기 화면을 표시한다. 기존 강아지가 있으면 새로고침 중·실패 후에도 목록과 사진 동작을 유지하고 재시도 안내를 보인다.
