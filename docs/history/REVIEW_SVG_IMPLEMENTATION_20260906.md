## 최신 재조회 · 2026-09-06 13:40 KST

검수 서버가 운영 DB에서 읽은 결과, 기존 승인견 8마리 모두 공개 SVG가 있다. 현재 전체 승인견은 12마리, 공개 SVG도 12개이며 승인 대기는 1마리다. 12개 확정 문서의 실제 정규화 SHA-256은 로컬 검수본과 일치하고, 공개 디자인 버전도 모두 일치한다. 하늘은 작은 구름이 떠 있는 최종 검수 도형이다.

아래의 ‘승인 8 / 공개 SVG 0’ 표와 미확정 설명은 최초 적용 당시 기록이며 현재 상태가 아니다. 이번 재조회에서는 승인·공개·배포를 실행하지 않았다. 실제 AIT 배포 상태는 별도 확인 대상이다. 조회 증거: `.tmp/svg-transition/publication-status-latest.json`.

## 최초 적용 당시 남은 확정과 전환 (현재 상태는 상단 재조회 참조)

1. 제작자가 [비교 화면](http://127.0.0.1:4178/.tmp/svg-transition/preview.html)의 기존 승인견 8마리(쿠키·치즈·몽이·배추·티티·우유·구르미·하늘)를 최종 확인합니다. 대기견 5마리는 승인 대상이 아닙니다.
2. 토스 QR에서 SVG 지원 AIT를 검증하고 공개 데이터 전환과 앱 활성화를 진행합니다. AIT는 로컬 private 후보만 생성했으며 업로드·출시는 하지 않았습니다. 현재 작업 트리의 다른 변경도 포함된 후보입니다.
3. 운영에서 새 소품 저장 후 동일 AIT 번들이 새 문서를 표시하는지 확인합니다. 로컬 도형 전달·저장 검증은 통과했지만 이 운영 실증은 아직 미완료입니다.
4. 구형 클라이언트 재실행 안내 전환 후 PNG 호환 API·DB 컬럼·RPC·빈 버킷을 후속 migration으로 제거합니다. 후보 SQL은 `supabase/rollout/retire-png-after-svg.sql`; 미전환 참조·남은 파일이 있으면 철거를 거부하며, 로컬 철거 테스트에서 사진·감사·SVG 버전 보존 확인.

전체 전환·PNG 철거 완료로 판정하지 않습니다. 제작자의 기존 승인견 최종 확인과 토스 QR 배포 검증이 남았습니다.
