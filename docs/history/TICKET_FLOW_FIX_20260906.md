## 완료 범위

로컬 구현·자동 검사·광고 OFF private AIT 생성까지 완료했다. 이번 수정의 Edge 재배포, Toss 업로드, 실기기 확인, 검토 요청, 출시는 아직 하지 않았다. DB 마이그레이션은 필요하지 않다. 광고·공유·알림 운영 설정과 실제 보상·등록·승인 기록은 변경하지 않았다.

- 공유 SDK가 콘솔 설정대로 보내는 `티켓` 단위를 프런트와 API가 받는다. 기존 대기 기록의 `강아지 티켓`도 호환하며, 다른 단위는 거부한다. 원래 요청 ID·이벤트 순서·재시도·서버 차감 검증은 유지한다. 이전 실패 세션에 보상을 임의 소급하지 않는다.
- 소진/광고 안내창을 연 상태에서 서버가 무료·보너스 티켓이나 기존 사진 권한을 확인하면 같은 친구의 만남 버튼으로 바뀐다. 시간 계산만으로 지급을 선언하거나 자동 입장/차감하지 않는다. 클릭 시 권한을 다시 확인하고 기존 간식·쓰다듬기를 유지한다.
- 광고 OFF는 새 광고 시작을 차단한다. 이미 완료된 광고 보상은 앨범 v2에서도 SQL의 소유자·강아지·완료 상태·중복 사용 검사를 거쳐 소비할 수 있다. 구형 비내구성 광고 경로는 그대로 차단한다.

## 사용자에게 실제로 적용되는 규칙

- 강아지 사진을 본다고 티켓을 지급하지 않는다. 새 사진 수집 성공 시 티켓 1장을 사용한다. 내 사진과 허용된 재열람은 무료다.
- 무료 티켓은 최대 2장, 3시간마다 1장이다. 자정 초기화는 없다.
- 무료·보너스 티켓이 모두 0이면 지원되는 공유 보상 버튼이 홈에 보인다. 미수집 친구를 누르면 공유/충전 안내, 광고 활성화 시 광고 선택 안내로 이어진다. 마지막 사진 위에 안내창을 강제로 띄우지 않는다.
- 공유는 서버가 확인한 이벤트로 보너스 티켓을 기록한다. 닫기 이벤트만으로 지급하지 않는다.
- 광고 완료 보상은 선택한 강아지를 한 번 만나는 권한이다. 자유 사용 티켓 잔액에 1장을 더하는 방식이 아니다. 하루 2회 제한과 자연 충전 시각은 유지한다.
