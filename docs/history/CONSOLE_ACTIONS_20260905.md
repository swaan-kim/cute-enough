## 광고 ON AIT에 필요한 설정

AIT 작업은 사용자가 별도로 진행한다. 다음 두 빌드 설정을 적용한 새 후보가 필요하다. 이 문서는 다른 작업 창에 자동 전달하지 않는다.

```dotenv
VITE_ADS_ENABLED=true
VITE_REWARDED_AD_GROUP_ID=ait.v2.live.285b758f6d564708
```

런타임은 기존 production 설정을 유지한다. 서비스 키·인증서는 추가하지 않는다. 새 후보의 deploymentId·SHA-256·바이트 크기와 실제 적용 플래그를 함께 기록한다. 현재 `20260905-23` 파일은 광고 OFF 그대로 보존한다.

새 광고 ON 후보 준비 후 이 작업에서 서버 Edge `AIT_REWARDED_ADS_ENABLED`와 DB `ads_enabled`를 맞춘다. 광고 보상은 기존대로 선택한 공개견의 사진 접근권이며, 콘솔 단위가 `강아지 티켓`이라고 광고 보상을 자유 사용 보너스 잔액에 더하지 않는다.
