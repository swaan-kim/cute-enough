## 원인과 변경

- 홈의 광고 안내가 클릭할 수 없는 `span`이었다. 실제 버튼 → 강아지 선택 → 기존 광고 확인창으로 연결했다.
- 광고는 일반 티켓 지급이 아니라 선택한 강아지를 만나는 권한이다. 광고 후에도 무료 티켓 숫자는 0일 수 있으며, 간식·쓰다듬기 → 사진 흐름을 유지한다.
- 내 강아지·무료 재열람 친구는 광고 선택에서 제외한다. 새로 만날 대상이 없으면 앨범으로 안내한다.
- 준비 중 티켓이 충전되면 광고 대신 서버가 확인한 무료/보너스 티켓을 사용한다.
- 광고 로드 중복을 직렬화하고, 오래된 로드는 다시 준비한다. 시작 이벤트가 없으면 15초 뒤 명시적 재확인 버튼을 표시한다. 타이머만으로 보상을 주거나 새 광고를 열지 않는다.
- `userEarnedReward`에서만 완료 기록을 남긴다. 광고 닫힘 이벤트가 누락되면 사용자가 앱에서 직접 계속할 수 있다. 취소·오류로 이미 받은 보상을 회수하지 않는다.
- 응답이 끊긴 광고 시작 요청은 같은 요청 ID로 복구한다. 완료 대기 기록은 취소보다 우선한다.
- 공개 중지/미수집 원본 소실로 사용할 수 없어진 광고 권한은 다른 유효한 친구로 한 번 옮길 수 있다. 구버전 RPC는 유지한다.
- 진단 이벤트는 단계·결과·소요 시간·허용된 오류 코드만 보낸다. 이름·사진·사용자 ID·원본 오류 URL은 보내지 않는다.
