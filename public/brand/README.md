# 오늘의 강아지 브랜드 자산

- `app-icon-600.png`: Apps in Toss 콘솔 업로드용 원본
- `app-icon-dark-600.png`: Apps in Toss 콘솔 다크모드 업로드용 원본
- `app-icon-512.png`: 웹 및 공유용
- `favicon-192.png`: 웹 파비콘
- `app-icon-camera-*-source.png`: 카메라형 로고 생성 원본
- `app-icon-polaroid-v1-*`, `favicon-polaroid-v1-*`: 이전 로고 백업
- `logo-concepts.png`: A/B/C 시안 비교 보드
- `concepts/`: 세 가지 원본 시안

앱 아이콘은 밝은 블러시 핑크 배경, 크림색 강아지, 앞발이 걸친 즉석카메라형 사진창으로 구성했습니다. 다크모드용은 동일한 형태에 코코아 로즈 배경을 적용했습니다. 토스 로고, 토스 그래픽 자산, 외부 음원이나 타사 상표는 포함하지 않습니다. `appName`은 기존 고유 ID인 `cute-enough`를 유지하고, 사용자에게 보이는 서비스명은 `오늘의 강아지`를 사용합니다.
